# 合成研究数据字典与预定义分析计划

数据许可：此项目自建合成样本，可随作品公开；不含真实参与者或真实论文结果。

| 字段 | 含义与规则 |
|---|---|
| participant_id | 非空且唯一；一行表示一个参与者的完整前后测配对 |
| group | control 或 treatment；分组不允许在执行中改变 |
| pre | 前测分数，0–100，空值表示缺失 |
| post | 后测分数，0–100，空值表示缺失 |

合成场景：研究助理需要核对一份模拟论文 Table 2 中报告的数值。T07 在模拟协议中撤回参与，排除规则先写入计划；C07 后测缺失。例子仅演示已声明的完整案例分析，不能推断真实缺失机制或随机化。

主对比：每人的 change=post-pre；treatment 的平均变化减去 control 的平均变化。使用双侧 Welch t 检验，95% 置信区间；不假定两组等方差。唯一主对比，不做探索性多重检验，不进行因果判定。

独立性、研究设计、测量有效性、完整案例分析是否可接受，均需研究者人工审查。Shapiro 检验仅辅助诊断，不自动选择统计方法，也不能证明假设满足。变化分数分析不等于 ANCOVA，两者不能偷偷互换。

## 手算 Oracle（独立于软件输出）

control 变化 [1,2,3,4,2,3]，treatment 变化 [4,5,6,7,5,6]。

- 两组各 n=6；均值分别 2.5 和 5.5；样本方差均为 1.1。
- 估计差异 5.5−2.5=3。
- SE=sqrt(1.1/6+1.1/6)=sqrt(11/30)。
- Welch df=10；t=3/sqrt(11/30)=4.954336943…。
- t(0.975,10)=2.2281388519649385（常用 t 分布参考值）；CI=3±2.2281388519649385×sqrt(11/30)。
- pooled SD=sqrt(1.1)，Cohen d=3/sqrt(1.1)。
- C1、C2 应匹配；C3 声称差异为 5，应判不匹配。不能通过自动修改预期值让错误主张通过。

JSON 计划绑定 CSV 的原始字节哈希；换行符改变也会产生新版本。修改数据后，应明确审核并重新绑定计划，不能自动接受数据漂移。
