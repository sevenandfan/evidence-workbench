选定 `MLforR.xlsx` → `Sunk Costs` 表：Paid 与 Free 两条件的 n、均值、SD、排除/未应答计数。参照为作者已发布 `ML_ESCIfromR.xls` → `ESCIfromR` 中 study1 的行。36 个站点与一个 Overall；总体纳入 n=6330，排除/未应答14。Mean across samples 的 n 是各站点平均值，不是独立样本，本轮明确排除该汇总行。

这是作者真实汇总统计的计算复现；不声称已重新核对个体数据清洗，也不是重做参与者实验。

## 方法与对照

- B0：独立数学参考实现；用标准库 log-gamma 与二分求根，遵循已审查作者公式路径。
- B1：明确输入契约、方法/方向/置信规则、哈希/来源、SciPy log-gamma 与 Brent 求根、逐行主张校验与报告。
- 外部 gold：作者先前发布的 R 输出表，不从本项目程序结果复制。
- 共同条件：同一切片、Paid−Free 对比、SMD 小样本修正与作者历史区间路径；点估计容差1e-7、区间端点1e-6。
- B0/B1共享 SciPy nct 分布求值。原生 Rscript 本机没有找到，不冒称作者完整 R 工程已复现。

## 发现与修正

1. 作者脚本注释写 Cohen d，但 metafor SMD 默认 correct=TRUE，对应 Hedges g。保留原始 d 与 J×d，不把两个指标混为一谈。
2. 原作者 n>1000 用99%区间，其他95%。若统一成95%将出现真实口径错误；按原规则复算。
3. 区间按作者把修正 g 传入 MBESS ci.smd 的历史路径复算；这是兼容原结果的选择，不是推荐新的统计分析如此使用。
4. XLS 解析器本机缺失，仅将 xlrd2.0.1 安装到项目 .tools；未修改全局环境。Excel 原表只读，未导出覆盖；Unknown extension 警告不影响原字节。
5. 验证脚本初版有一处无用条件表达式导致语法错误；删除后实际运行通过，全部项目 Python 文件完成 compileall。统计结果未因该语法错误改变。

## 三项验收与放行

正确性：固定切片与独立既有 gold 对照通过；原始研究的因果有效性、跨站点推广和作者完整清洗未认证。

生效性：固定commit/逐文件哈希；类型/方向/方法/容差拒绝；gold污染、错版本、重复站点、非法n与零SD负例有证据；每行连到原表与参考表单元格；单命令复算与回放可运行。

净价值：真实案例现在能集成生成对照表、区间图和证据。用户本人核对、定位错误耗时与实际使用收益未测，不写效率提高百分比。

放行：**一个真实汇总统计研究切片的本地计算复现完成**。陌生环境安装/Docker/CI、原生R重跑、参与者级数据清洗、未见过的研究任务和用户答辩仍待审。下一优先项是同研究的参与者级切片与更独立的统计参照；不需要立即换另一个大数据集。
