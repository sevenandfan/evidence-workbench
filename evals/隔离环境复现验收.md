仅适用于本轮Windows/Python3.11的SciPy下载恢复：

```powershell
python scripts/fetch_verified_scipy.py
python scripts/check_clean_environment.py --verified-scipy .tools/wheelhouse/scipy-1.11.4-cp311-cp311-win_amd64.whl
```
